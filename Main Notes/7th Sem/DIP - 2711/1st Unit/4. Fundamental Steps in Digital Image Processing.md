## 4. Fundamental Steps in Digital Image Processing
- Digital Image Processing include steps that are used to enhance the useful imformation inside of an image.

**1. Image Acquistion**
- Involves the step of capturing an image and storing it as a digital file using sensors and specialized hardware for imagery.
- Quality of this step is directly related to the qualities of other steps.
- Includes preprocessing like scaling.


**2. Image Enhancement**
- This is used to enchance the image usability according to the need , for eg , human interpretation. It invlolves 
	- Adjusting Brightness , saturation
	- Reducing noise.
	- Sharpening Details.

**3. Image Restoration**
- This is used to undo the effects of degrading qualities.
	- Blurring 
	- Noise
	- Distortion 


**3. Color Image Processing**
- This step includes processing of the image in two ways 
	- Full Colour
	- Pseudo-Color 
- This has gained wide spread usage due to the increasing usage of images world-wide.

**4. Wavelets and Multi-Resolution Processing**
- Wavelets is the representation of image in different resolutions. 
	- This allows for analysis of the image at various degrees of details
	
**5. Compression**
- Images are compressed in two ways
	- Lossless
		- The original image can be perfectly reconstruced from the comprossed data.
	- Lossy
		- Some details of the images are lost in the compressed data and cannot be recovered but this allows for the size to be greatly reduced.

**6. Morphological Processing**
- This process involves processing the images based on it's shape to extract useful information that can be used to represent and describe object

**7. Segmentation**
- This process involves slicing the image into constituent objects or parts.
	- Used to simplify the image's representation
	- Often the most challenging part in DIP.

**8. Representation and Description**
- The segmented parts are then represented in a form that is easier to interpret for the computers as a whole zone or a region. 
- The description phase then extracts features from the representation eg boundaries , planes etc.

**9. Object Recognition**
- This phase then assigns labels to the features in the image using various ML algorithms.
