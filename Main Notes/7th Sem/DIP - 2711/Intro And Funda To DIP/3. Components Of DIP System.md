## Components Of DIP System

- Image sensors
	- These are devices which are sensitive to light eg X-Ray , Gamma Rays and produce analog signals. Eg CCD (Charge-Couple Device)
	- Digitizer is then used to convert these analog signals in digital signal.
- Specialized Image Processing Hardware
	- These take up the digital signal produced by the digitizer and then perform calculations on it. It consists of 
		- ALU (Arithmetic Logic Unit)
			- This module does all the mathematical computation required for the algorithms. For eg real time noise reduction
		- GPU (Graphical Processing Unit)
			- This is used majorly in performing large scale matrix transformations 
		- Frame Buffers
			- These are specialized data structures which hold the information for an image. This helps in fast reterival enabling real time transformations such as panning , scrolling , zooming
			- Typically stored in RAM.
- CPU
	- This can be any general purpose CPU.
		- Used to manager other components and run image processing softwares	
- Image Processing Softwares
	- Specialized software that applies various transformation on the image
		- Eg noise reduction , blur , segmentation 
	- Modular design so that other programmers can integrate this into their own code.
- Mass storage
	- Image needs high data storage (1024x1024 8bit image requires 1 MB of storage.)
		- Short-Term storage -> RAM is typically used to load the image when active processing is going on
		- On-line storage -> SSD or Hard Drive is typically used for long term storage 
- Image Display
	- Hardware powered by GPU which are used to display the images.
- Hardcopy
	- Copy of the image being sent to hardware that create a hardcopy of it.
- Cloud Storage
	- Storage that is not locally accessible is used to store archival images
		- Main issue is of bandwidth as images are storage heavy
		- Image compression algorithm are used to transmit images over the internet.
