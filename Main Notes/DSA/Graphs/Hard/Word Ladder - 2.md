# Word Ladder - 2
- *Problem* *Statement*: 
	A transformation sequence from word beginWord to word endWord using a dictionary wordList is a sequence of words beginWord -> s_1 -> s_2 -> ... -> s_k such that:
	* Every adjacent pair of words differs by a single letter.
	* Every s_i for 1 <= i <= k is in wordList. Note that beginWord does not need to be in wordList.
	* s_k == endWord
	Given two words, beginWord and endWord, and a dictionary wordList, return all the shortest transformation sequences from beginWord to endWord, or an empty list if no such sequence exists. Each sequence should be returned as a list of the words [beginWord, s_1, s_2, ..., s_k].
#### Solution
- Phew this question is tuff.


* So this question will apply both [[BFS]] and [[DFS]]
	- BFS will be done similar to that of [[Word Ladder - 1]] but here we will be keeping a depthMap that will track for each word how many steps it took to create it.  
		- Just like i was storing it in the struct.
	- This map will be used in the backtracking while performing DFS.  
```cpp
q.push(beginWord);
set.erase(beginWord);
depthMap[beginWord] = 0;

while (!q.empty()) {
  string word = q.front();
  q.pop();

  if (word == endWord)
	break;

  int steps = depthMap[word];
  for (int i = 0; i < word.size(); i++) {
	char original = word[i];
	for (char ch = 'a'; ch <= 'z'; ch++) {
	  word[i] = ch;
	  if (set.find(word) != set.end()) {
		q.push(word);
		set.erase(word);
		depthMap[word] = steps + 1;
	  }
	  word[i] = original;
	}
  }
}
```


#### DFS

- Now for the DFS part.
	- Using DFS we will be backtracking from the endWord to the startWord
	- How will DFS work in this situation?
		- It will rebuild all the words using the depthMap and by keeping the count of the steps we will be able to rebuild the recursion tree.
			![[Pasted image 20250425020851.png]]
			- The DFS will first complete the 'dot' path and then while coming back will complete the 'lot' part.
	- When we encounter the beginWord. 
		- Because we are backtracking , the sequence array contains the order in reverse order.
			- So we need to reverse the seq array and push it into the ans vec which stores all the paths.
			- Then we again reverse the sequence so that when the dfs is coming back it's popping the correct elements
		

##### How is the DFS code working?
```cpp
int steps = depthMap[word];
for (int i = 0; i < word.size(); i++) {
  char original = word[i];
  for (char ch = 'a'; ch <= 'z'; ch++) {
	word[i] = ch;
	if (depthMap.find(word) != depthMap.end() and
		depthMap[word] + 1 == steps) {
	  seq.push_back(word);
	  dfs(word, beginWord, seq, depthMap, ans);
	  seq.pop_back();
	}
  }
  word[i] = original;
}

```
- In this part what we are doing is rebuilding the words again , but to ensure that only the previous word that was suppossed to be put , for eg we need hot to be generated after bot , the loop may make a word that is in the depthMap but is not the previous word of the bot , to counter this situation we use the condition of depthMap[word] + 1 == steps. 
	- word will be the previous word generated by the loop. i.e hot , and we already stored the steps it took to reach bot , so hot steps + 1 should be equal to the steps it took to reach bot. 
	- This ensures that only the shortest sequences are counted and in order.
- To accomodate for future sequence we pop the last element after coming back from one DFS , so that another branch can use the seq array	



#### Complete Code
```cpp
#include <algorithm>
#include <queue>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>

using namespace std;

class Solution {
public:
  vector<vector<string>> findLadders(string beginWord, string endWord,
                                     vector<string> &wordList) {
    queue<string> q;
    unordered_set set(wordList.begin(), wordList.end());

    vector<vector<string>> ans;
    unordered_map<string, int> depthMap;
    q.push(beginWord);
    set.erase(beginWord);
    depthMap[beginWord] = 0;

    while (!q.empty()) {
      string word = q.front();
      q.pop();

      if (word == endWord)
        break;

      int steps = depthMap[word];
      for (int i = 0; i < word.size(); i++) {
        char original = word[i];
        for (char ch = 'a'; ch <= 'z'; ch++) {
          word[i] = ch;
          if (set.find(word) != set.end()) {
            q.push(word);
            set.erase(word);
            depthMap[word] = steps + 1;
          }
          word[i] = original;
        }
      }
    }

    if (depthMap.find(endWord) != depthMap.end()) {
      vector<string> seq = {endWord};
      dfs(endWord, beginWord, seq, depthMap, ans);
    }
    return ans;
  }

  void dfs(string word, string beginWord, vector<string> &seq,
           unordered_map<string, int> &depthMap, vector<vector<string>> &ans) {
    if (word == beginWord) {
      reverse(seq.begin(), seq.end());
      ans.push_back(seq);
      reverse(seq.begin(), seq.end());
    }
    int steps = depthMap[word];
    for (int i = 0; i < word.size(); i++) {
      char original = word[i];
      for (char ch = 'a'; ch <= 'z'; ch++) {
        word[i] = ch;
        if (depthMap.find(word) != depthMap.end() and
            depthMap[word] + 1 == steps) {
          seq.push_back(word);
          dfs(word, beginWord, seq, depthMap, ans);
          seq.pop_back();
        }
      }
      word[i] = original;
    }
  };
};

```
