# Graph And Types


#### Introduction
- The nodes are called vertex.
- The path connecting two nodes or vertex is called edge.
	![[Pasted image 20250417163153.png]]


#### Types
- Directed -> From one node , you can only go to the node that is directed outwards. Unidirectional movement. * *
- Undirected -> Biredectional Movement.



#### Cycles
- Starting from one node , you end up on the same node from any path. It has a cycle --> Called undirected cyclic graph if the graph is undirected and directed cyclic graph if it is a directed graph (DAG).

#### Path
- Contain a lot of nodes and vertices and each of them reachable.
- A node cannot appear twice in a path.
- For Directed Graph
	- Indegree - Number of edges coming in to the node
	- Outdegree - Number of outgoing edges from a nod e


#### Degree of a Node
- Number of edge connected to a node in undirected graph.
- *Property - Total degree of a graph = 2 * number of edges* 
#### Edge Weights
- Cost of the edge.
- If there is no cost defined , assume unit cost
